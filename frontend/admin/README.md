# MatchingJobs admin

Admin portal. Dev server: http://localhost:5173

Shared UI, API, and auth live in `frontend/shared` and are imported as `@shared`. There is nothing to install inside `shared`.

```bash
yarn
yarn dev
```

Copy `.env.example` to `.env` if the API is not on port 8000. See `docs/learning/07-FRONTEND.md`.
